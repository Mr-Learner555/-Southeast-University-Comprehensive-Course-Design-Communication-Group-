# 东南大学综合课程设计 (通信组)
**Southeast University Comprehensive Course Design (Communication Group)**

---

## 📖 项目简介
这是东南大学2025年秋季大四课程综合课程设计 (通信组)的大作业，我们用Verilog实现了2FSK和QPSK数字调制方案，相关信息将在后续更新:)

## ✅ 已实现功能
- 二进制频移键控 (2FSK) 调制器
- 正交相移键控 (QPSK) 调制器
- 模块化设计，便于后续扩展解调模块

## 🛠️ 技术栈
- 硬件描述语言：**Verilog HDL**
- 开发工具：Xilinx Vivado
- 仿真工具：ModelSim / Vivado Simulator
